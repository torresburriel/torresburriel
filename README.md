# Daniel Torres Burriel

I've been designing digital experiences for more than 25 years. I run [Torresburriel Estudio](https://www.torresburriel.com), a UX consultancy with teams in Spain and Latin America, and I'm a member of UX Alliance.

These days I also build products: small tools I use every day, made with AI and published in the open. I'm interested in what happens when the people who design can also build.

- **[Lector for Mac](https://github.com/torresburriel/lector-mac)**: its desktop app. [Download](https://github.com/torresburriel/lector-mac/releases/latest).
